About Avalon

Avalon is an RPG which was released in 1998 for the PC. The game was made by some RPG enthousiasts which wanted to create an RPG by using only original art, music, code and their own storyline. The result of their efforts is a freeware game for everybody who enjoys the genre and appreciates classic gameplay.
